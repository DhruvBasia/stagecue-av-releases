# StageCue AV: installers

Windows installers for **StageCue AV**, a dual-screen cue controller for live events (projector output, PDF booklets and web flipbooks, a speaker timer, captions and a crew phone remote).

**Download:** [latest release](https://github.com/DhruvBasia/stagecue-av-releases/releases/latest) → `StageCue-AV-Setup-x.y.z.exe`

- Windows 10/11, 64-bit. Installs for your user only, with no admin rights needed.
- The installer is not code-signed yet, so if Windows SmartScreen warns, click **More info → Run anyway**.
- After the first install, StageCue updates itself from this page. New versions download in the background and install when you close StageCue (it never restarts during a show).

This repository only holds the installers; the source code is private.
